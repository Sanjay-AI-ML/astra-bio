# Current frontend source baseline

Captured before the 11 October 2026 navigation simplification and Google Stitch design selection.

The `frontend/` directory preserves the React main view, nutrition component, stylesheet, interaction test source, HTML entry, Vite configuration and exact dependency manifests. It contains no credentials, device data, food logs, snapshots, model binaries, installed dependencies or compiled outputs.

Use this archive to review or restore the visual implementation. It is not a standalone runnable copy; API data and the test fixture remain in the main project. The supplied Vercel design is a separate design option.
